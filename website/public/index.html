特性

该有的都有，
不该打扰的一样没有。

实时预览

标题、列表、引用写完即呈现；粗体与行内代码在光标进入时才展开标记。⇧⌘M 一键切换源码模式，文本、选区与撤销历史原样保留。

# 墨落成文**记录此刻** → 墨落成文 记录此刻

文件树与全文搜索

侧栏浏览整个项目，⇧⌘F 递归搜索所有文本文件，点击结果精准定位并保持高亮。

专注与打字机模式

F8 淡出杂念，只留当前段落；F9 让光标始终居于屏幕中央。

表格就地编辑

管道表格直接渲染，单元格点击即改，Tab 导航、增删行列与对齐控制一应俱全。

公式与图表

KaTeX 公式与 Mermaid 图表离线渲染，导出 PDF / HTML 时原样嵌入。

代码高亮

30+ 常用语言离线着色，语言标识一键点击修改，明暗主题自适应。

本地图片

截图直接粘贴，自动存入文档同级 assets/ 并写好相对路径，中文与空格路径无忧。

导出与打印

分页或连续长页 PDF、自包含 HTML，公式图表完整保留；系统打印面板随时待命。

文档安全

UTF-8 与混合行尾保真、外部修改保护、崩溃恢复草稿；你的文字只留在你的电脑里。
