# Inkpot 功能说明与工程文档

这是 Inkpot 桌面应用工程的主入口，基于 AppKit、WKWebView 与 CodeMirror 6，面向日常中文与 Markdown 写作。仓库保持单一工程结构，原生应用与 Web 编辑器实现紧密协同。

## 功能概览

Inkpot 核心功能覆盖日常写作、富格式呈现与文档管理：

| 功能模块 | 范围 | 说明 |
| --- | --- | --- |
| Markdown 基础高亮 | 标题、强调、列表、链接、代码 | 基于 CodeMirror CommonMark 与 Lezer 语法解析 |
| 查找与替换 | 当前文档查找、前后导航、替换、全部替换 | 支持区分大小写、整词匹配、正则搜索与捕获组替换 |
| 基础实时模式 | 六级标题、粗体、斜体、列表、引用 | 局部展开行内格式，保持块级渲染，接近 Typora 的编辑体验 |
| 常用格式操作 | 粗体、斜体、删除线、行内代码、链接、标题、列表、代码块与分隔线 | 快捷键与菜单支持，增删对应标记，支持独立撤销 |
| 原生标签页与多窗口 | 原生窗口标签栏、新建标签、拆分与合并窗口 | 采用 AppKit 原生标签组，各文档独立持有一套编辑器 |
| 自动配对 | 括号、方括号、英文双引号、反引号与星号 | 自动闭合或包裹选区，输入法组合输入期间自动规避 |
| 基础写作交互 | 列表与引用回车续写、空项逐层退出、退格取消标记、标题回车换行 | 复用 Markdown 结构命令，编辑限制在当前行 |
| 代码块与语法着色 | 反引号/波浪号围栏、语言首行编辑、缩进调整、30 种常用语言着色 | 离线语言包按需加载，明暗主题自适应，导出与打印排版一致 |
| 标题大纲 | 侧栏层级导航、正文滚动自动同步高亮、折叠与调整宽度 | 原生 `NSOutlineView` 与增量语法树同步 |
| 文件树 | 打开文件夹、自然排序、展开折叠、同窗口切换、右键新建/重命名/删除 | 目录懒加载，支持标准系统废纸篓安全删除与重名保护 |
| 文件夹全文搜索 | 侧栏递归搜索当前文件夹 Markdown 与文本文件 | 后台异步遍历，支持定位跳转与匹配高亮 |
| 专注与打字机模式 | 专注模式淡化非当前块，打字机模式保持光标垂直居中 | 纯视图呈现，不污染撤销历史与文件内容，全局记住偏好 |
| 设置窗口 | 启动方式、字体与字号、默认打开模式、拼写检查、外观、图片目录、专注／打字机模式与自动保存 | 原生设置窗口（⌘,）；启动方式下次启动生效，其余偏好即时同步 |
| 本地恢复与保存保护 | 协调写入校验、外部修改保护、输入停止后自动保存本地恢复草稿 | 保护文件基线，避免意外丢失与并发冲突覆盖 |
| 本地图片 | 实时预览、系统面板插入与图片粘贴 | 自动复制至文档同级 `assets/` 相对路径，支持空格与中文路径 |
| 基础表格 | 管道表格预览、单元格就地编辑、键盘导航、增删行列与对齐 | 支持表头与末列保护、独立撤销；结构操作仅重新序列化当前表格 |
| 基础公式 | 块级 `$$` 与行内 `$` 公式实时渲染、点击展开源码编辑、插入公式块 | 基于 KaTeX 离线资源按需加载，安全隔离不执行非法脚本 |
| GFM 扩展语法 | 删除线、任务列表可点击复选框、脚注悬停提示、高亮、`[toc]` 目录 | 语法树增量解析，任务状态点击即时同步源码 |
| 字数统计 | 底部状态栏显示当前编辑模式，并实时显示字数、字符数与行数 | 中日韩按字统计，西文按词统计，编辑行增量计算 |
| 明暗外观 | 跟随系统外观或在设置中固定浅色/深色 | 页面内自适应与原生界面协同，导出统一固定浅色 |
| 导出与打印 | 导出连续单页 PDF 与独立 HTML，系统打印面板分页 | 免面板直接输出至同级目录，公式与图表完整内联 |
| 拖拽操作 | 拖拽 Markdown/文本文件打开，拖拽图片文件插入相对路径 | 原生拖拽集成 |
| 富文本粘贴 | 实时模式下自动将剪贴板 HTML 转为 Markdown 格式 | 源码模式保持纯文本粘贴，保留原始行尾风格 |
| 字体与字号设置 | 正文与代码分别选择系统已安装字体与字号 | 偏好全局持久化，多窗口即时同步 |
| Mermaid 图表 | 顶层 `mermaid` 围栏离线渲染、点击展开编辑、错误回退 | 离线携带完整运行库，HTML/PDF 导出嵌入独立 SVG |
| 窗口与会话恢复 | 正常退出后恢复窗口位置、标签顺序、文件与侧栏状态 | 自动记住上次会话，丢失文件友好提示 |
| 可选自动保存 | 停止输入约 2 秒后自动保存已保存过的文档 | 默认关闭，开启后沿用外部修改保护 |

## 编辑与核心交互行为

### 基础实时模式

- 默认采用实时模式：六级井号标题、下划线式标题、普通列表和引用保持渲染呈现，光标进入不会还原整块源码。
- 粗体、斜体、行内代码与链接在光标进入或选区覆盖时局部展开对应 Markdown 标记；移出后恢复渲染。标题与引用的隐藏前缀作为键盘导航的整体，避免光标逐字穿过不可见字符；在内容起点退格可取消标记。
- 显示菜单的“源码模式”（⇧⌘M）可随时在纯文本源码与实时预览之间无缝切换；切换保留文档文本、当前选区和撤销历史。
- 搜索命中隐藏标记时，仅临时展开当前匹配项，移动选区后恢复。中文输入法组合输入期间冻结装饰重建，组合确认后再更新预览。

### 写作交互与自动配对

- 列表与引用：末尾按 Enter 自动续写同级项目；有序列表自动计算下一序号并保留编号风格。空项目按 Enter 逐层退出嵌套。在项目内容起点按 Backspace 取消当前缩进或前缀标记。
- 标题：末尾按 Enter 换行并回到普通正文段落。
- 符号自动配对：输入 `(`、`[`、英文双引号、反引号或 `*` 自动补全闭合符号；若存在选区，则直接包裹选区内容。转义字符后、粘贴或中文输入法组合期间不触发配对。

### 代码块与语法着色

- 实时模式下，三个及以上反引号或波浪号组成的闭合代码块呈现为等宽浅底区域。代码内部文字不解析为正文格式。
- 首行语言标识呈现为交互按钮，点击仅展开首行供编辑语言名称；按 Enter 返回代码正文，按 Esc 退出首行编辑。按 ⌘Enter 可直接跳出代码块并在其后创建正文段落。
- 语法着色覆盖 30 种常用语言及别名（JavaScript/TypeScript/JSON、Python、HTML/CSS、Shell、SQL、YAML、TOML、Swift、Go、Rust、C/C++/ObjC、Java、Kotlin、C#、Ruby、Lua、Diff、Dockerfile、Markdown 等）。代码包采用按需离线动态加载，未识别语言保持纯文本显示。

### 标题大纲与文件树

- 标题大纲：左侧侧栏支持纯文本大纲层级视图。支持六级井号标题与两级下划线式标题，支持点击跳转定位。正文滚动时视口当前章节自动高亮。
- 文件树：侧栏支持目录树浏览。按自然顺序排序，仅列举 Markdown 及纯文本文件（`.md`、`.markdown`、`.txt`），过滤隐藏文件、软链接与包目录。子目录展开时后台懒加载。
- 文件切换与安全：单击文件在当前窗口打开（复用同一个 WebKit 视图）；若原文档有未保存修改，严格触发保存/放弃/取消确认提示。右键支持新建文件/文件夹、重命名和移至系统废纸篓。

### 文件夹内全文搜索

- 快捷键 ⇧⌘F 在侧栏开启全文搜索页。
- 递归检索当前文件树根目录下所有支持的文本文件，后台线程异步流式匹配，单次最多展示 1000 处匹配。
- 搜索结果按文件分组展示行号与摘要，点击精准定位至对应文件的行列位置并保持高亮。

### 专注与打字机模式

- 专注模式（F8）：淡化光标所在段落/代码块/表格/公式块之外的内容，保持当前编辑块高亮。
- 打字机模式（F9）：编辑与光标移动时，光标所在行自动滚动至窗口垂直居中区域。
- 两项模式均纯属视图呈现，不产生编辑事务，不进入撤销历史，在多窗口间即时同步偏好。

### 本地图片与富文本粘贴

- 本地图片：支持 Markdown 本地图片语法实时预览，双击展开源码。通过“格式 → 插入本地图片…”或粘贴图片，自动将文件存入文档同级的 `assets/` 相对路径目录，保留原图数据。
- 富文本粘贴：实时模式下粘贴剪贴板中的 HTML 内容时，自动转换为 Markdown 格式（标题、加粗、斜体、列表、链接、简单表格等）；源码模式与代码块内部始终保持纯文本粘贴。

### 基础表格与公式

- 表格：识别 Markdown 管道表格并就地呈现。点击单元格直接编辑，支持 Tab / ⇧Tab 水平导航，Enter / ⇧Enter 上下单元格跳转，⌘Enter 退出表格。菜单提供插入行列、删除行列与对齐控制。
- 公式：支持行内 `$…$` 与块级 `$$…$$` 公式的 KaTeX 实时排版渲染。点击公式展开 LaTeX 源码编辑，移开后恢复公式排版。离线打包全部字体与脚本，渲染采用沙箱限制，不执行恶意脚本。

### GFM 语法、统计与明暗外观

- GFM 语法：支持删除线（`~~`）、高亮（`==`）、脚注（`[^1]`）、任务列表（`- [ ]` / `- [x]`）及段落 `[toc]` 自动目录块生成。任务复选框支持点击直接切换勾选状态。
- 字数统计：底部状态栏实时统计中日韩汉字（按字）、西文（按词）、不含换行字符数与行数。采用行级增量更新算法，大文档编辑无明显卡顿。
- 明暗外观：跟随系统主题或在设置中手动固定为浅色或深色，编辑器与原生界面自适应切换配色。

### 导出与打印

- 导出为 PDF：生成连续单页 PDF 文档（A4 宽度适应），公式与图表完整矢量渲染。
- 导出为 HTML：生成自包含样式、MathML 公式与内联图片的独立 HTML 文件。
- 打印：系统标准打印面板（⌘P），支持页面设置、页边距与分页断页保护。

### 会话恢复与自动保存

- 正常退出应用时记录所有窗口的位置、前后顺序、标签页列表、文件树与侧栏状态；下次启动自动恢复。
- 可选自动保存：可在设置中开启，停止输入约 2 秒后对已有路径的文档触发保存；外部冲突或未命名文档保持手动保存确认保护。

## 性能设计与基线

为了保障大文档编辑的流畅度，编辑器核心进行了以下优化：

1. **共享顶层块索引**：公式、目录、Mermaid 图表与表格共享一份顶层语法块索引；光标在未涉及区域移动时，直接复用既有装饰，避免不必要的重新计算。
2. **增量字数统计**：字数统计由 CodeMirror StateField 进行行级增量计算，仅重算产生改动的行。
3. **行尾差异映射**：行尾映射仅记录与占多数的主行尾不同的例外换行，大幅减少编辑时的换行表重建开销。

### 基准测试数据（无界面 Chromium，约 77 万字符中英混合文档）

| 场景 | 优化前中位／P99 | 优化后中位／P99 |
| --- | --- | --- |
| 1MB 文档正文按键 | 48.3／105.7 ms | 10.8／53.5 ms |
| 1MB 文档移动光标 | 40.4／67.6 ms | 0.2／3.8 ms |
| 1MB 含 `[toc]` 按键 | 59.8／70.3 ms | 19.8／29.0 ms |

## 数据安全约定与实际限制

### 数据安全机制

- **字符编码与行尾保真**：文档严格以 UTF-8 往返，保留 UTF-8 BOM；精确保留 LF、CRLF、CR 混合行尾；新增行沿用文件首个行尾风格。遇到无效编码文件拒绝打开，不做破坏性有损解码。
- **文件保存协调**：写入文件经由系统协调写入流程（`NSFileCoordinator`），比对载入基线，检测外部并发修改并阻止静默覆盖，提供冲突另存保护。
- **本地恢复草稿**：停止输入约 1 秒后自动保存草稿至 `~/Library/Application Support/Inkpot/Recovery/`（目录权限 `0700`，草稿权限 `0600`）。文档正常保存或关闭后清理对应草稿。若遇非正常中断，下次启动或通过菜单均可恢复副本。

恢复草稿是本机未加密 JSON，包含文档内容和原路径；恢复时打开副本，不自动覆盖原文件。最后约 1 秒的输入、未确认候选及快照失败后的新增内容可能未保存，草稿不能代替文件备份。组合输入期间不采集未确认候选，保存、模式切换及表格结构操作保留对应保护。

### 实际功能边界与限制

- **不内置扩展/插件系统**：不承载第三方插件、扩展市场或复杂脚本环境。
- **不内置 Vim 模式**：聚焦于标准的 macOS 原生文本编辑体验。
- **不抓取远程图片**：本地图片仅处理本地文件路径与相对目录，不提供网络图床上传或自动爬取。
- **不引入重型文档转换**：不依赖外部庞大转换链（如 Pandoc/Office 格式互转）。

## 本地构建与验证

### 环境要求

- macOS 15.0 或更高版本
- 已验证 Xcode 27.1
- Node.js 22.12 或更高版本；CI 使用 22.x

### 常用构建命令

不改变系统全局 `xcode-select`，在当前命令环境中指定 `DEVELOPER_DIR`：

```bash
# 1. 构建 Web 编辑器资源与离线渲染库
cd CoreEditor
node .yarn/releases/yarn-4.18.0.cjs install --immutable
node .yarn/releases/yarn-4.18.0.cjs build
node .yarn/releases/yarn-4.18.0.cjs test --runInBand
cd ..

# 2. 代码静态检查与原生构建
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
swiftlint lint --strict --config .swiftlint.yml
xcodebuild build -project App/Inkpot.xcodeproj -scheme Inkpot \
  -destination 'platform=macOS' -derivedDataPath build/Debug \
```
